# 🔋 XBatteryStatus

> Windows 시스템 트레이에서 블루투스 기기의 배터리 잔량을 모니터링하고, 배터리가 부족하면 **Xbox 도전과제 스타일 팝업**으로 알려드립니다 (도전과제 달성: 컨트롤러 배터리 방전 🤣)

## ✨ 기능

- 🎮 **다중 기기 모니터링**: 배터리 서비스가 있는 페어링된 모든 블루투스 기기를 자동 감지합니다 (Xbox 컨트롤러, 블루투스 이어폰, 블루투스 키보드/마우스, 타사 컨트롤러 등). **블루투스 주소로 중복 제거**하여 같은 이름의 기기가 혼동되지 않습니다
- 🟢 **Xbox 도전과제 스타일 팝업**: 하단 중앙에 원이 팝인 → 카드로 확장 → 광택이 스쳐 지나감 → 자동으로 접힘. Windows 11 Xbox Game Bar 도전과제 알림을 충실히 재현했습니다
- 🎚️ **3단계 맞춤 임계값**: 기기마다 3개의 잔량 값을 각각 설정할 수 있습니다 (기본 35% / 30% / 25%). 임계값을 넘어 내려가면 한 번 알림. 급격한 하락도 감지합니다 (예: 51% → 49%도 발동)
- ✏️ **완전 커스터마이즈 가능한 팝업**: 제목/부제목 텍스트(`{battery}`, `{device}` 플레이스홀더 지원), 줄마다 독립된 폰트, 전체 배율(100%~200%), **대화형 위치 지정**(방향키로 미세 조정, Enter로 확인)
- 🔔 **알림음**: 내장 사운드 여러 개, 사용자 정의 `.wav` 지원(exe 옆 `sound` 폴더에 넣기만 하면 됨), 기본 음소거
- 🌍 **다국어 UI**: 중국어 간체, 영어, 러시아어, 스페인어, 포르투갈어, 독일어, 일본어, 프랑스어, 폴란드어, 한국어, 아랍어. 중국어 시스템에서는 자동으로 중국어로 전환
- 🚀 **Windows 시작 시 실행**: 기본 활성화, 원클릭 토글
- 📄 **로그 토글**: 필요할 때 상세 로그 활성화, exe 폴더에 기록 (10MB 제한, 자동 절삭)
- 📁 **휴대성**: 모든 파일(설정, 로그, 사운드)이 exe 폴더 안에만 존재 — 시스템을 오염시키지 않습니다

## ⚙️ 사용 방법

프로그램은 시스템 트레이에 상주합니다. 트레이 아이콘을 우클릭:

| 메뉴 항목 | 설명 |
|---|---|
| 🌗 Theme | 아이콘 테마: 자동 / 밝게 / 어둡게 |
| 🌐 Language | UI 언어 (Auto는 시스템 설정을 따름) |
| 🎮 Devices | 기기 관리: 알림, 임계값, 이름, 폴링 간격, 로그 |
| 🎨 Popup Settings | 팝업 설정: 텍스트, 폰트, 크기, 위치 |
| 🚀 Windows 시작 시 실행 | 로그온 시 실행 (기본 활성화) |
| 🔔 소리 | 알림음 선택 (기본 음소거) |
| ❌ Exit | 프로그램 종료 |

## 🎨 팝업 설정

- **제목 / 부제목**: 사용자 정의 텍스트. 비워 두면 현재 언어의 기본 문구가 사용됩니다. 부제목은 플레이스홀더를 지원합니다:
  - `{battery}` → 실제 배터리 잔량 (예: `35`)
  - `{device}` → 기기 표시 이름
- **폰트**: 제목 줄과 부제목 줄에 각각 **독립된 폰트**(크기, 굵기)를 설정
- **크기**: 전체 배율 100%~200%, 모든 요소가 비례적으로 확대됩니다
- **위치**: "Set Position..."을 클릭하면 팝업이 상주 표시되며, **방향키로 한 번 누르면 1px, 길게 누르면 10px 이동**, `Enter`로 확정, `Esc`로 취소. "Reset Position"으로 언제든 하단 중앙으로 복귀
- **테스트**: 즉시 테스트 팝업 표시. "Test (5s)"는 5초 후 표시되어 게임 전체화면 상황을 확인하기에 편리합니다

## 🎮 기기

- 배터리 서비스가 있는 페어링된 블루투스 기기를 자동 나열 (주소로 중복 제거)
- 기기별 설정:
  - ✅ 배터리 부족 알림 활성화 여부 (컨트롤러는 기본 활성화)
  - 🔢 알림할 배터리 값 3개 (1~100%)
  - ✏️ 표시 이름 지정 (비우면 기기 이름, 팝업의 `{device}` 플레이스홀더에 사용)
- **폴링 간격**: 배터리 읽기 주기(초, 기본 15초)
- **로그 활성화**: 체크하면 상세 실행 로그 기록

## 🌍 언어

11개 언어 지원: 중국어 간체, 영어, 러시아어, 스페인어, 포르투갈어, 독일어, 일본어, 프랑스어, 폴란드어, 한국어, 아랍어.

- **Auto**(기본): 시스템이 중국어 간체이면 중국어, 그 외에는 영어. 나머지 언어는 수동 선택
- 수동 전환은 트레이 메뉴에서 가능

## 🔔 소리

- 트레이 메뉴 "소리" → "음소거" 또는 오디오 파일 선택 (메뉴 항목은 파일명으로 표시)
- 사용자 정의 사운드: `.wav` 파일을 **exe 옆 `sound` 폴더**에 넣기만 하면 메뉴가 자동 갱신됩니다. 재시작 불필요
- `.wav` 형식만 지원

## 📁 파일 및 디렉터리

휴대용 설계로, 모든 파일이 **exe 디렉터리**에 생성됩니다:

```
📁 exe 디렉터리/
├── 📄 XBatteryStatus.exe      ← 메인 프로그램
├── 📄 log.txt                 ← 실행 로그 (로그 활성화 시 기록, 10MB 제한)
├── 📁 sound/                  ← 사운드 폴더 (읽기 전용, 사용자 wav를 여기에)
└── 📁 config/                 ← 모든 설정
    ├── 📄 settings.json       ← 앱 설정 (언어/팝업/소리/자동 시작 등)
    └── 📄 devices.json        ← 기기별 알림 설정
```

## ⚠️ 주의사항

- **독점 전체화면**(Exclusive Fullscreen) 게임에서는 팝업을 표시할 수 없습니다. 이는 모든 서드파티 도구에 해당하는 Windows 제한입니다. 게임을 **테두리 없는 창**(Borderless Windowed) 모드로 전환하세요
- 사용자 정의 사운드는 `.wav`만 지원
- 알림은 "**임계값 교차 시 한 번**" 방식입니다. 충전으로 임계값 이상 올라갔다가 다시 내려와야 재알림됩니다. 임계값 미만 상태로 재연결된 기기도 한 번 알림

## 🛠️ 빌드

**.NET 8 SDK**(Windows)가 필요합니다.

```bash
dotnet build XBatteryStatus/XBatteryStatus.csproj -c Release
```

출력 위치: `XBatteryStatus/bin/Release/net8.0-windows10.0.19041.0/`

- 내장 사운드는 빌드 시 출력의 `sound/` 폴더로 자동 복사됩니다
- `config/`와 `log.txt`는 실행 시 exe 옆에 자동 생성됩니다. 수동 생성 불필요

## ❓ Q&A

- Q: 이 프로젝트를 만든 이유는?

- A: 기존 도구는 Windows 알림으로 알려주지만, 게임 중에는 Windows가 최우선 순위가 아닌 알림을 기본적으로 차단해서 수동으로 최우선 순위로 설정해야 해서 번거롭습니다. 설정을 해도 한동안 지나면 Windows가 '컨트롤러 배터리 앱의 알림을 끌까요?'라고 묻습니다. 알림을 한 번도 열지 않았기 때문에 Microsoft가 중요하지 않다고 판단해 끄기를 권장하기 때문입니다. 그래서 네이티브 알림 채널을 우회해 다른 방식으로 알림을 구현했습니다.

- Q: 어댑터가 정확한 배터리 잔량을 표시하지 못하는 이유는?

- A: XInput은 4단계(Empty 빈 / Low 낮음 / Medium 중간 / Full 가득)만 제공하며, Bluetooth GATT 같은 정확한 백분율이 없습니다. 이는 XInput 프로토콜 자체의 한계이며, 제가 어떻게 할 수 없습니다.
