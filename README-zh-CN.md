## ✨ 功能特性

- 🎮 **多蓝牙设备监控**：自动发现所有带电池服务的已配对蓝牙设备（Xbox 手柄、蓝牙耳机、蓝牙键鼠、其他品牌手柄等），按**蓝牙地址去重**，同名设备不会混淆
- 🟢 **Xbox 成就风格悬浮窗**：底部居中的圆形图标弹出 → 展开成卡片 → 光泽扫过 → 自动收起，一比一复刻 Windows 11 Xbox Game Bar 的成就弹窗动画
- 🎚️ **三档自定义提醒**：每台设备可单独设置 3 个电量提醒值（默认 35% / 30% / 25%），跨过阈值时提醒一次，支持跳电检测（如 51% 直接掉到 49% 也会触发）
- ✏️ **弹窗完全自定义**：标题/副标题文本（支持 `{battery}`、`{device}` 占位符）、两行独立字体、整体缩放（100%~200%）、**交互式定位**（方向键微调，回车确认）
- 🔔 **提示音**：内置多款提示音，支持自定义 wav 文件（放入 exe 旁 `sound` 文件夹即可），默认静音
- 🌍 **多语言界面**：简体中文、英语、俄语、西班牙语、葡萄牙语、德语、日语、法语、波兰语、韩语、阿拉伯语；系统为简体中文时自动切换中文
- 🚀 **开机自启**：默认开启，一键开关
- 📄 **日志开关**：按需开启，日志写入 exe 目录（上限 10MB 自动截断）
- 📁 **绿色便携**：所有文件（配置、日志、提示音）均在 exe 所在目录内，不污染系统

## ⚙️ 使用说明

程序常驻系统托盘，右键托盘图标：

| 菜单项 | 说明 |
|---|---|
| 🌗 Theme | 图标主题：自动 / 浅色 / 深色 |
| 🌐 Language | 界面语言（Auto 跟随系统） |
| 🎮 Devices | 设备管理：启用提醒、设置阈值、自定义名称、轮询间隔、日志开关 |
| 🎨 Popup Settings | 弹窗设置：文本、字体、大小、位置 |
| 🚀 开机自启 | 开机自动运行（默认开启） |
| 🔔 提示音 | 选择提醒音效（默认静音） |
| ❌ Exit | 退出程序 |

## 🎨 弹窗设置

- **标题 / 副标题**：自定义文本；留空则使用当前语言的默认文案。副标题支持占位符：
  - `{battery}` → 实际电量（如 `35`）
  - `{device}` → 设备显示名称
- **字体**：标题行、副标题行**分别独立设置**字体（字号、粗细）
- **大小**：整体缩放 100% ~ 200%，弹窗内所有元素等比放大
- **位置**：点击"设置位置..."后弹窗常驻显示，**点按方向键移动 1px、长按 10px**，`Enter` 确认、`Esc` 取消；可随时"重置位置"回到底部居中
- **测试**：立即弹出测试弹窗；"Test (5s)" 5 秒后弹出，方便切进游戏验证全屏场景

## 🎮 设备管理

- 自动列出所有带电池服务的已配对蓝牙设备（按蓝牙地址去重）
- 每台设备可单独设置：
  - ✅ 是否启用低电量提醒（默认仅手柄启用）
  - 🔢 3 个提醒电量值（1~100%）
  - ✏️ 自定义显示名称（留空使用设备名，用于弹窗 `{device}` 占位符）
- **轮询间隔**：电量读取频率（秒，默认 15s）
- **启用日志**：勾选后开始记录详细运行日志

## 🌍 多语言

支持 11 种语言：简体中文、英语、俄语、西班牙语、葡萄牙语、德语、日语、法语、波兰语、韩语、阿拉伯语。

- **Auto**（默认）：系统区域为简体中文时自动使用中文，其他语言默认为英语，由于比较麻烦没有编写自动切换机制，请手动切换。
- 可在托盘菜单中手动切换

## 🔔 提示音

- 托盘菜单「提示音」→「静音」或选择音频文件（菜单项按文件名列出）
- 自定义音频：将 `.wav` 文件放入 **exe 同目录的 `sound` 文件夹**，右键菜单打开时自动刷新，无需重启
- 仅支持 `.wav` 格式

## 📁 文件与目录

程序为绿色便携设计，所有文件都生成在 **exe 所在目录**：

```
📁 exe 所在目录/
├── 📄 XBatteryStatus.exe      ← 主程序
├── 📄 log.txt                 ← 运行日志（启用日志后生成，上限 10MB）
├── 📁 sound/                  ← 提示音文件夹（只读，可放入自定义 wav）
└── 📁 config/                 ← 所有配置
    ├── 📄 settings.json       ← 应用设置（语言/弹窗/提示音/开机自启等）
    └── 📄 devices.json        ← 每台设备的提醒配置
```

## ⚠️ 注意事项

- **独占全屏游戏**（Exclusive Fullscreen）无法显示悬浮窗——这是 Windows 的系统限制，所有第三方工具均如此；请在游戏中切换为**无边框窗口化**模式
- 提示音仅支持 `.wav` 文件
- 电量提醒采用"**跨过阈值提醒一次**"策略：充电回升后再次跌破才会重新提醒；设备断开重连后如果电量已在阈值以下也会提醒一次

## 🛠️ 构建说明

需要 **.NET 8 SDK**（Windows 系统）。

```bash
dotnet build XBatteryStatus/XBatteryStatus.csproj -c Release
```

构建输出位于 `XBatteryStatus/bin/Release/net8.0-windows10.0.19041.0/`：

- 内置提示音会随构建自动复制到输出目录的 `sound/` 文件夹
- `config/` 配置与 `log.txt` 日志在运行时自动生成于 exe 所在目录，无需手动创建

## ❓ QA

- Q: 为什么要做这个项目?

- A: 因为现有的工具是用Windows通知进行提醒，而你玩游戏的时候，Windows会默认屏蔽非最高优先级的通知，你还需要手动设置为最高优先级，一是比较麻烦，二是即使你设置好了优先级，用一段时间后，Windows就会询问你是否要关闭手柄提醒软件的通知，因为你从来没有点开过它的通知，微软认为它不重要，会推荐你关闭（很傻B）所以我才要绕开原生通知这个通道，用其他方式来实现提醒。

- Q: 为什么适配器无法看到准确电量?

- A: XInput 只提供 4 档电量（Empty 空 / Low 低 / Medium 中 / Full 满），没有蓝牙 GATT 那种精确百分比——这是 XInput 协议本身的限制，我对此无能无力。
