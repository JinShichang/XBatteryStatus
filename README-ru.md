## ✨ Возможности

- 🎮 **Мониторинг нескольких устройств**: автоматически находит все сопряжённые Bluetooth-устройства со службой заряда (геймпады Xbox, Bluetooth-наушники, Bluetooth-клавиатуры и мыши, геймпады других брендов и т.д.), исключает дубликаты по **Bluetooth-адресу**, поэтому устройства с одинаковыми именами не путаются
- 🟢 **Всплывающее уведомление в стиле Xbox**: круг появляется внизу по центру → расширяется в карточку → пробегает блик → автоматически сворачивается. Точная копия анимации достижений Xbox Game Bar в Windows 11
- 🎚️ **Три уровня напоминаний**: для каждого устройства можно задать 3 своих значения заряда (по умолчанию 35% / 30% / 25%). Напоминание срабатывает один раз при пересечении порога, с обнаружением резких падений (например, 51% → 49% тоже сработает)
- ✏️ **Полная настройка уведомления**: текст заголовка/подзаголовка (с плейсхолдерами `{battery}` и `{device}`), отдельные шрифты для двух строк, общий масштаб (100%–200%), **интерактивное позиционирование** (стрелки для точной настройки, Enter для подтверждения)
- 🔔 **Звуки уведомлений**: несколько встроенных звуков, поддержка своих `.wav` файлов (просто положите их в папку `sound` рядом с exe), по умолчанию без звука
- 🌍 **Многоязычный интерфейс**: упрощённый китайский, английский, русский, испанский, португальский, немецкий, японский, французский, польский, корейский, арабский; автоматически переключается на китайский на китайских системах
- 🚀 **Автозапуск с Windows**: включён по умолчанию, переключается одним кликом
- 📄 **Включение журнала**: подробный журнал при необходимости, пишется в папку exe (лимит 10 МБ, автоусечение)
- 📁 **Портативность**: все файлы (конфигурация, журнал, звуки) хранятся в папке exe — ничего не засоряет систему

## ⚙️ Использование

Программа живёт в системном трее. Щёлкните правой кнопкой по значку:

| Пункт меню | Описание |
|---|---|
| 🌗 Theme | Тема значка: Авто / Светлая / Тёмная |
| 🌐 Language | Язык интерфейса (Auto следует за системой) |
| 🎮 Devices | Управление устройствами: напоминания, пороги, имена, интервал опроса, журнал |
| 🎨 Popup Settings | Настройка уведомления: текст, шрифты, размер, положение |
| 🚀 Запуск с Windows | Автозапуск при входе в систему (включён по умолчанию) |
| 🔔 Звук | Выбор звука уведомления (по умолчанию без звука) |
| ❌ Exit | Выход из программы |

## 🎨 Настройка уведомления

- **Заголовок / Подзаголовок**: свой текст; оставьте пустым, чтобы использовать локализованный текст по умолчанию. Подзаголовок поддерживает плейсхолдеры:
  - `{battery}` → фактический уровень заряда (например, `35`)
  - `{device}` → отображаемое имя устройства
- **Шрифты**: строка заголовка и строка подзаголовка имеют **отдельные независимые шрифты** (размер, начертание)
- **Размер**: общий масштаб от 100% до 200%, всё масштабируется пропорционально
- **Положение**: нажмите "Set Position...", уведомление останется на экране; **стрелки двигают на 1 пиксель за нажатие, на 10 при удержании**, `Enter` подтверждает, `Esc` отменяет; "Reset Position" в любой момент возвращает вниз по центру
- **Тест**: мгновенно показывает тестовое уведомление; "Test (5s)" показывает его через 5 секунд — удобно проверить полноэкранные сценарии в игре

## 🎮 Устройства

- Автоматически перечисляет все сопряжённые Bluetooth-устройства со службой заряда (исключая дубликаты по адресу)
- Для каждого устройства можно настроить:
  - ✅ Включены ли напоминания о низком заряде (геймпады включены по умолчанию)
  - 🔢 3 значения заряда для напоминаний (1–100%)
  - ✏️ Своё отображаемое имя (пусто — имя устройства; используется плейсхолдером `{device}`)
- **Интервал опроса**: как часто читать заряд, в секундах (по умолчанию 15 с)
- **Включить журнал**: при отметке записывается подробный журнал работы

## 🌍 Языки

Поддерживается 11 языков: упрощённый китайский, английский, русский, испанский, португальский, немецкий, японский, французский, польский, корейский, арабский.

- **Auto** (по умолчанию): китайский при китайской локали системы, иначе английский; остальные языки выбираются вручную
- Ручное переключение доступно в меню трея

## 🔔 Звук

- Меню трея «Звук» → «Без звука» или выбор аудиофайла (пункты меню перечислены по имени файла)
- Свои звуки: положите `.wav` файлы в **папку `sound` рядом с exe**; меню обновится автоматически, перезапуск не нужен
- Поддерживается только `.wav`

## 📁 Файлы и папки

Программа портативна — всё создаётся в **папке exe**:

```
📁 папка exe/
├── 📄 XBatteryStatus.exe      ← главная программа
├── 📄 log.txt                 ← журнал (пишется при включённом журнале, лимит 10 МБ)
├── 📁 sound/                  ← папка звуков (только чтение, кладите сюда свои wav)
└── 📁 config/                 ← вся конфигурация
    ├── 📄 settings.json       ← настройки приложения (язык/уведомление/звук/автозапуск и т.д.)
    └── 📄 devices.json        ← настройки напоминаний для каждого устройства
```

## ⚠️ Примечания

- **Эксклюзивный полноэкранный режим** (Exclusive Fullscreen) не может показывать уведомление — это ограничение Windows, распространяющееся на все сторонние инструменты; переключите игры в режим **без рамки** (Borderless Windowed)
- Для своих звуков поддерживается только `.wav`
- Напоминания работают по правилу «**один раз за пересечение порога**»: повторно напоминает только после зарядки выше порога и нового падения; устройство, подключившееся уже ниже порога, тоже напомнит один раз

## 🛠️ Сборка

Требуется **.NET 8 SDK** (Windows).

```bash
dotnet build XBatteryStatus/XBatteryStatus.csproj -c Release
```

Результат записывается в `XBatteryStatus/bin/Release/net8.0-windows10.0.19041.0/`:

- Встроенные звуки автоматически копируются в папку `sound/` результата сборки
- `config/` и `log.txt` создаются в рантайме рядом с exe; вручную создавать ничего не нужно

## ❓ Вопросы и ответы

- В: Зачем был создан этот проект?

- О: Существующие инструменты оповещают через уведомления Windows, но во время игры Windows по умолчанию скрывает уведомления ниже максимального приоритета, и приходится вручную выставлять максимальный приоритет — это неудобно. Даже после настройки через некоторое время Windows спрашивает, не отключить ли уведомления приложения контроля заряда геймпада — ведь вы их никогда не открывали; Microsoft считает их неважными и предлагает отключить. Поэтому я обошёл штатный канал уведомлений и реализовал оповещения другим способом.

- В: Почему адаптер не показывает точный уровень заряда?

- О: XInput предоставляет только 4 уровня (Empty пусто / Low низкий / Medium средний / Full полный) и не даёт точных процентов, как GATT по Bluetooth. Это ограничение самого протокола XInput, и я ничего не могу с этим поделать.
