## ✨ 機能

- 🎮 **複数デバイスの監視**: バッテリーサービスを持つペアリング済み Bluetooth デバイス（Xbox コントローラー、Bluetooth ヘッドホン、Bluetooth キーボード・マウス、他社コントローラーなど）を自動検出。**Bluetooth アドレスで重複排除**するため、同名デバイスが混同されることはありません
- 🟢 **Xbox 実績風ポップアップ**: 下部中央に円がポップイン → カードに展開 → 光沢が走る → 自動で収縮。Windows 11 の Xbox Game Bar 実績トーストを忠実に再現
- 🎚️ **3段階のカスタムしきい値**: デバイスごとに 3 つの残量値を個別設定可能（既定 35% / 30% / 25%）。しきい値を下回ったときに 1 回通知。急激な低下も検出（例: 51% → 49% でも発動）
- ✏️ **完全カスタマイズ可能なポップアップ**: タイトル/サブタイトルのテキスト（`{battery}` と `{device}` のプレースホルダー対応）、行ごとの独立フォント、全体スケール（100%–200%）、**対話式の位置調整**（矢印キーで微調整、Enter で確定）
- 🔔 **通知音**: 内蔵サウンド複数種、独自 `.wav` 対応（exe の隣の `sound` フォルダーに置くだけ）、初期状態はミュート
- 🌍 **多言語 UI**: 簡体字中国語、英語、ロシア語、スペイン語、ポルトガル語、ドイツ語、日本語、フランス語、ポーランド語、韓国語、アラビア語。中国語システムでは自動的に中国語へ切り替え
- 🚀 **Windows 起動時に自動起動**: 既定でオン、ワンクリック切り替え
- 📄 **ログ切り替え**: 必要なときに詳細ログを有効化。exe フォルダーに書き出し（上限 10 MB、自動切り詰め）
- 📁 **ポータブル**: 全ファイル（設定・ログ・サウンド）が exe フォルダー内に収まり、システムを汚しません

## ⚙️ 使い方

アプリはシステムトレイに常駐します。トレイアイコンを右クリック:

| メニュー項目 | 説明 |
|---|---|
| 🌗 Theme | アイコンのテーマ: 自動 / ライト / ダーク |
| 🌐 Language | 表示言語（Auto はシステムに追従） |
| 🎮 Devices | デバイス管理: 通知、しきい値、名前、ポーリング間隔、ログ |
| 🎨 Popup Settings | ポップアップ設定: テキスト、フォント、サイズ、位置 |
| 🚀 Windows と一緒に起動 | ログオン時に実行（既定でオン） |
| 🔔 サウンド | 通知音の選択（初期状態はミュート） |
| ❌ Exit | 終了 |

## 🎨 ポップアップ設定

- **タイトル / サブタイトル**: 任意のテキスト。空欄にすると現在の言語の既定文が使われます。サブタイトルはプレースホルダーに対応:
  - `{battery}` → 実際の残量（例: `35`）
  - `{device}` → デバイスの表示名
- **フォント**: タイトル行とサブタイトル行で**それぞれ独立したフォント**（サイズ、太さ）を設定
- **サイズ**: 全体スケール 100%～200%、すべての要素が比例して拡大
- **位置**: 「Set Position...」をクリックするとポップアップが常駐表示され、**矢印キーで 1 回押し 1px、長押し 10px 移動**、`Enter` で確定、`Esc` でキャンセル。「Reset Position」でいつでも下部中央に戻せます
- **テスト**: すぐにテストポップアップを表示。「Test (5s)」は 5 秒後に表示され、ゲームのフルスクリーン状況の確認に便利

## 🎮 デバイス

- バッテリーサービスを持つペアリング済み Bluetooth デバイスを自動一覧表示（アドレスで重複排除）
- デバイスごとに設定可能:
  - ✅ 残量低下通知を有効にするか（コントローラーは既定で有効）
  - 🔢 通知する 3 つの残量値（1～100%）
  - ✏️ 表示名のカスタマイズ（空欄はデバイス名。ポップアップの `{device}` プレースホルダーに使用）
- **ポーリング間隔**: バッテリーを読み取る頻度（秒、既定 15 秒）
- **ログを有効化**: オンにすると詳細な実行ログを記録

## 🌍 言語

11 言語に対応: 簡体字中国語、英語、ロシア語、スペイン語、ポルトガル語、ドイツ語、日本語、フランス語、ポーランド語、韓国語、アラビア語。

- **Auto**（既定）: システムが簡体字中国語なら中国語、それ以外は英語。その他の言語は手動で選択
- 手動切り替えはトレイメニューから

## 🔔 サウンド

- トレイメニュー「サウンド」→「ミュート」または音声ファイルを選択（メニュー項目はファイル名で表示）
- 独自サウンド: `.wav` ファイルを **exe の隣の `sound` フォルダー**に配置。メニューは自動更新され、再起動は不要
- 対応形式は `.wav` のみ

## 📁 ファイルとディレクトリ

ポータブル設計のため、すべて **exe と同じディレクトリ**に生成されます:

```
📁 exe ディレクトリ/
├── 📄 XBatteryStatus.exe      ← メインプログラム
├── 📄 log.txt                 ← 実行ログ（ログ有効時のみ、上限 10 MB）
├── 📁 sound/                  ← サウンドフォルダー（読み取り専用、独自 wav をここへ）
└── 📁 config/                 ← 全設定
    ├── 📄 settings.json       ← アプリ設定（言語/ポップアップ/サウンド/自動起動など）
    └── 📄 devices.json        ← デバイスごとの通知設定
```

## ⚠️ 注意事項

- **独占フルスクリーン**（Exclusive Fullscreen）のゲームではポップアップを表示できません。これは Windows の制限で、すべてのサードパーティ製ツールに該当します。ゲームは**境界線なしウィンドウ**（Borderless Windowed）モードに切り替えてください
- 独自サウンドは `.wav` のみ対応
- 通知は「**しきい値を下回ったら 1 回**」方式です。再通知は充電でしきい値より上がり、再び下がったときのみ。しきい値未満の状態で再接続されたデバイスも 1 回通知します

## 🛠️ ビルド

**.NET 8 SDK**（Windows）が必要です。

```bash
dotnet build XBatteryStatus/XBatteryStatus.csproj -c Release
```

出力先: `XBatteryStatus/bin/Release/net8.0-windows10.0.19041.0/`

- 内蔵サウンドはビルド時に出力先の `sound/` フォルダーへ自動コピーされます
- `config/` と `log.txt` は実行時に exe の隣に自動生成されます。手動作成は不要

## ❓ Q&A

- Q: このプロジェクトを作った理由は?

- A: 既存ツールは Windows 通知で知らせますが、ゲーム中は Windows が最高優先度以外の通知を既定でブロックし、手動で最高優先度に設定する必要があり面倒です。設定しても、しばらくすると Windows が「コントローラー電池アプリの通知をオフにしますか?」と聞いてきます。通知を一度も開いていないため、Microsoft は重要ではないと判断してオフを推奨するからです。そこでネイティブ通知チャンネルを迂回し、別の方法で通知を実装しました。

- Q: アダプターで正確な残量が見えないのはなぜ?

- A: XInput は 4 段階（Empty 空 / Low 低 / Medium 中 / Full 満）しか提供せず、Bluetooth GATT のような正確なパーセントはありません。これは XInput プロトコル自体の制限であり、どうすることもできません。
